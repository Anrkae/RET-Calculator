MANUAL DE REINICIO DO BOT LOCAL

Quando o computador reinicia, param:
- n8n
- WPPConnect
- ngrok

A sessao do WhatsApp pode continuar salva, mas a URL do ngrok geralmente muda.

PASSO 1
Abra o Docker Desktop.
Espere ele ficar com status Running.

PASSO 2
Abra o PowerShell e rode:

cd C:\whatsapp-automation
docker compose up -d
docker ps

Depois confira se apareceram os containers n8n e wpp-server.

PASSO 3
No mesmo PowerShell, rode:

docker logs wpp-server --tail 30

Se aparecer algo como "Server is running on port: 21465", o WPPConnect subiu corretamente.

PASSO 4
Abra outro PowerShell e rode:

cd C:\ngrok
.\ngrok.exe http 5678

O ngrok vai mostrar uma linha parecida com:

Forwarding https://xxxxx.ngrok-free.dev -> http://localhost:5678

Copie a URL publica.

PASSO 5
Abra a URL publica do ngrok no navegador para confirmar que o n8n esta acessivel.

Exemplo:
https://xxxxx.ngrok-free.dev

PASSO 6
Se a URL do ngrok mudou, atualize o arquivo:

src/js/services/atendimentos-service.js

Procure a constante CANCELAMENTO_WEBHOOK_URL e troque pela nova URL.

Exemplo:
const CANCELAMENTO_WEBHOOK_URL = "https://nova-url.ngrok-free.dev/webhook/cancelamento-whatsapp";

PASSO 7
Se voce alterou a URL no projeto, publique essa mudanca no GitHub Pages.

Fluxo:
1. salvar o arquivo
2. fazer commit
3. enviar para o GitHub
4. esperar o GitHub Pages atualizar

PASSO 8
Abra o n8n em:

http://localhost:5678

Abra o workflow do bot e confira se ele esta com o botao Active ligado.

PASSO 9
Teste o webhook manualmente no PowerShell:

Invoke-RestMethod `
  -Method Post `
  -Uri "https://SUA-URL-NGROK/webhook/cancelamento-whatsapp" `
  -ContentType "application/json" `
  -Body '{"operator":"123456","cancelCountOfDay":4,"reason":"Mudança de endereço","duration":"02:15","time":"10:32:00"}'

Se estiver tudo certo, a mensagem deve chegar no grupo do WhatsApp.

PASSO 10
Teste no app real:
1. abra o site
2. faca login
3. inicie um atendimento
4. finalize como Cancelado
5. escolha o motivo
6. conclua

A mensagem deve ser enviada automaticamente para o grupo.

PASSO 11
Se o WhatsApp parecer desconectado, rode:

$full = 'equipe-ret:$2b$10$bQGW19PUHqAGJ14.fznW4efbEnfg9cMFF6A9Pq9yLESY39t4MtBia'
$sessionParam = [uri]::EscapeDataString($full)

Invoke-RestMethod `
  -Method Get `
  -Uri "http://localhost:21465/api/$sessionParam/status-session"

Se estiver desconectado, pode ser necessario gerar QR e reconectar o WhatsApp.

cd C:\whatsapp-automation

3. abrir o ngrok:
cd C:\ngrok
