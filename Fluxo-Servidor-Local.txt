FLUXO LOCAL DO BOT

1. Abrir o Docker Desktop.

2. Subir os containers:
cd C:\whatsapp-automation
docker compose up -d
docker ps

3. Conferir o WPPConnect:
docker logs wpp-server --tail 30

4. Abrir o n8n:
http://localhost:5678

5. Confirmar que o workflow do bot esta Active.

6. Rodar o worker da fila:
cd "C:\Users\anrk0\OneDrive\Documentos\VS Code\RET-Calculator"
npm.cmd run process:cancelamento-fila -- --service-account "C:\Local Server\claro-ret-firebase-adminsdk-fbsvc-e1295c0804.json"

7. Testar no app:
- registrar um cancelamento
- verificar se chegou mensagem no grupo

EXPLICACAO RAPIDA

- O site grava cancelamentos em cancelamentoFila.
- O worker le essa fila.
- O worker chama o n8n local.
- O n8n envia no grupo pelo WPPConnect.

SE DER PROBLEMA

- confira se o workflow do n8n esta Active
- confira se o worker esta rodando
- confira se o WhatsApp esta conectado
- confira no Firebase se o documento entrou em cancelamentoFila
