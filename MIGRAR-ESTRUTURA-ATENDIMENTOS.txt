MIGRACAO PARA A NOVA ESTRUTURA

Nova colecao principal:
registrosAtendimento

Regras da migracao:
- tudo que for anterior a 01/04/2026 sera apagado da estrutura antiga
- tudo que for a partir de 01/04/2026 sera migrado para registrosAtendimento
- depois de migrar, o documento antigo tambem sera apagado

Nada sera apagado da nova estrutura durante a migracao.

PASSO 1
Baixe a service account do Firebase.

Caminho:
Firebase Console
Projeto claro-ret
Configuracoes do projeto
Contas de servico
Gerar nova chave privada

PASSO 2
No terminal, dentro do projeto, instale a dependencia:

npm.cmd install

PASSO 3
Rode a migracao:

npm.cmd run migrate:estrutura -- --service-account "CAMINHO_DO_JSON"

Exemplo:

npm.cmd run migrate:estrutura -- --service-account "C:\Users\SeuUsuario\Downloads\claro-ret-firebase-adminsdk.json"

PASSO 4
Ao final, o script vai mostrar:
- ligacoes analisadas
- ligacoes apagadas por serem anteriores a 01/04/2026
- ligacoes migradas para registrosAtendimento
- ligacoes ignoradas por data invalida

OBSERVACOES

- O script pode ser executado com o projeto local aberto normalmente
- Os documentos antigos a partir de 01/04/2026 sao migrados e removidos da estrutura antiga
- Os documentos anteriores a 01/04/2026 sao apenas apagados
